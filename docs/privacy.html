プライバシーポリシー

ふくふく（以下「運営」）は、「ふくふく｜福井エキマエ」（以下「本サービス」）での個人情報を、次のとおり取り扱います。

1. 取得する情報

  • お店の管理者のメールアドレス（招待・ログインのため）
  • お問い合わせフォームで送信された店名・ご連絡先・ご用件
  • 有料プランの契約情報（Stripe の顧客ID・契約の状態）。クレジットカード番号は Stripe が管理し、運営は取得・保存しません

2. 利用目的

  • お店の管理画面へのログイン、掲載内容の管理
  • お問い合わせ・更新依頼への対応
  • 有料プランの提供と、お支払いの確認
  • 本サービスに関する重要なお知らせ

3. 外部サービスの利用

本サービスは次の外部サービスを利用しており、上記の情報はこれらのサービス上に保存・処理されます。

  • Supabase（データベース・ログイン・写真の保存）
  • Stripe（決済）
  • GitHub Pages（ウェブサイトの配信）

4. 第三者への提供

法令に基づく場合を除き、ご本人の同意なく第三者に提供しません。

5. ブラウザへの保存

ウェブサイトでは、表示の設定（グルメ／夜のお店、エリア）とログイン状態を、お使いのブラウザに保存します。アクセス解析や広告のための Cookie は使用していません。

6. 開示・訂正・削除

ご自身の情報の開示・訂正・削除を希望される場合は、yasu29fr@gmail.com までご連絡ください。
